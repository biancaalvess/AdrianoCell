# AdrianoCell

## Sobre o Projeto

Esta aplicação é uma landing page moderna e responsiva, desenvolvida para representar as três unidades das lojas AdrianoCell. O objetivo é servir como vitrine digital para serviços de assistência técnica e venda de acessórios, facilitando a comunicação com os clientes e a visualização de produtos.

## Detalhes Técnicos

### Stack Tecnológica
A aplicação utiliza tecnologias de ponta para garantir performance e uma interface rica em componentes:

* **Framework:** Next.js 16.0.3 (App Router).
* **Biblioteca Base:** React 19.2.0.
* **Linguagem:** TypeScript.
* **Estilização:** Tailwind CSS 4 com suporte a animações via `tailwindcss-animate`.
* **Componentes de UI:** Radix UI (Accordion, Dialog, Tabs, Tooltip, etc.) para garantir acessibilidade e componentes robustos.
* **Gestão de Temas:** `next-themes` para suporte a modos claro e escuro.
* **Formulários:** React Hook Form com validação via Zod.

### Funcionalidades da Interface
* **Design Responsivo:** Adaptado para dispositivos móveis e desktops via Tailwind CSS.
* **Componentes Interativos:** Utilização de carrosséis (Embla Carousel), menus de navegação e áreas de scroll personalizadas.
* **Feedback ao Usuário:** Notificações via Sonner e componentes de Toast.
* **Visualização de Dados:** Integração com Recharts para possíveis dashboards informativos.

## Estrutura de Desenvolvimento

O projeto foi construído sobre uma arquitetura modular:

1.  **Segurança de Tipos:** Uso integral de TypeScript para evitar erros em tempo de execução.
2.  **Performance:** Otimização nativa do Next.js para renderização e SEO.
3.  **Analytics:** Integrado com Vercel Analytics para monitoramento de tráfego.

## Como Executar

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/biancaalvess/AdrianoCell.git](https://github.com/biancaalvess/AdrianoCell.git)
    ```
2.  **Instale as dependências:**
    ```bash
    npm install
    ```
3.  **Inicie o ambiente de desenvolvimento:**
    ```bash
    npm run dev
    ```
4.  **Acesse a aplicação:**
    Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
